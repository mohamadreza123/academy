# سامانه آکادمی ورزشکاران — نسخه اصلاح‌شده

این نسخه چند مشکل اصلی پروژه قبلی را برطرف می‌کند:

- ورود واقعی با حساب جداگانه برای هر ورزشکار
- مدیر هنگام ساخت ورزشکار، رمز اختصاصی تعیین می‌کند
- ورزشکار با حساب خودش وارد می‌شود و به پنل مدیر دسترسی ندارد
- ثبت کل شهریه، مبلغ پرداخت‌شده، مانده و تاریخ آخرین پرداخت
- ثبت سابقه چند پرداخت برای هر ورزشکار
- حذف حساب ورزشکار
- تنظیم نام آکادمی و لوگو
- کلید `SERVICE_ROLE` فقط در backend استفاده می‌شود و داخل HTML قرار نمی‌گیرد
- RLS دیتابیس برای جلوگیری از دسترسی عمومی مستقیم تنظیم شده است

## راه‌اندازی

1. در Supabase یک پروژه بسازید.
2. محتوای `supabase-schema.sql` را در SQL Editor اجرا کنید.
3. فایل `.env.example` را با نام `.env` کپی کنید.
4. مقدارهای زیر را در `.env` قرار دهید:
   - `SUPABASE_URL`
   - `SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`
   - `ADMIN_EMAIL`
5. اجرا:
   ```bash
   npm install
   npm start
   ```
6. آدرس `http://localhost:3000` را باز کنید.

### ساخت مدیر
در Supabase Dashboard از بخش Authentication > Users یک کاربر با همان `ADMIN_EMAIL` بسازید و برایش رمز تعیین کنید. این حساب وارد پنل مدیر می‌شود.

### نکته امنیتی
`SUPABASE_SERVICE_ROLE_KEY` را هرگز داخل `index.html` یا کد سمت مرورگر قرار ندهید و آن را در GitHub عمومی منتشر نکنید.
