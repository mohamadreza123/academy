# Academy — مرحله ۱

این نسخه از سایت، ورود مربی را از سمت مرورگر خارج کرده و به بک‌اند منتقل می‌کند.

## اجرا
1. Node.js 18+ نصب باشد.
2. `npm install`
3. `.env.example` را به `.env` تبدیل کنید.
4. برای رمز مدیریت یک bcrypt hash بسازید و در `ADMIN_PASSWORD_HASH` قرار دهید.
5. شماره واقعی مربی را در `ADMIN_PHONE` قرار دهید.
6. `npm start`

## امکانات مرحله ۱
- ورود مدیریت با شماره موبایل + رمز عبور سمت سرور
- session امن و HTTP-only cookie
- محدودیت تلاش ورود
- هدرهای امنیتی
- مدیریت بنر، عنوان‌ها، لوگو، شماره تماس، آدرس و لینک Instagram/Telegram/WhatsApp از پنل مربی
- ذخیره تنظیمات در `data/site.json`

## نکته مهم امنیتی
رمز واقعی داخل `index.html` یا JavaScript قرار نگرفته است. شماره و رمز مدیریت باید در `.env` تنظیم شوند و `.env` نباید داخل GitHub commit شود.
